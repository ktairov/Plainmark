# Исправления по ревью

## 1. Независимые запросы новых вкладок

Незавершённые чтения отслеживаются по отдельным запросам. Новый переход отменяет только предыдущие запросы замены текущей заметки; явные открытия новых вкладок сохраняются. Если такой запрос завершился после более позднего выбора, документ открывается в фоне. Операции закрытия/смены workspace по-прежнему отменяют устаревшие чтения. Watcher и очередь внешних файлов ожидают завершения всех актуальных чтений.

Проверено: `go test ./...`, `go vet ./...`, `go test -race ./internal/desktop`. Добавлены сценарии обоих порядков завершения двух Cmd/Ctrl-открытий, выбора существующей вкладки во время чтения, обычного перехода после Cmd/Ctrl-клика и дедупликации одинаковых запросов. Прежние проверки последних обычных переходов, watcher, закрытия и смены workspace проходят.

## 2. Подтверждённая запись настроек и повторные попытки

Удалён fingerprint, который отмечал состояние сохранённым ещё при постановке в очередь. Writer отдельно хранит последний запрос и подтверждённый успешной записью снимок. При ошибке он автоматически повторяет запись актуального снимка с паузой от 100 мс до 5 с; новый снимок заменяет устаревший. Одинаковые запросы не вызывают дополнительные записи и не сбрасывают backoff. Результаты попыток возвращаются UI, а сообщение о сбое снимается после успешного восстановления. При закрытии выполняется последняя попытка записи без бесконечного ожидания повторов.

Проверено: `go test ./...`, `go vet ./...`, race для desktop/settings. Тесты используют реальную временную файловую систему: вместо папки конфигурации сначала существует файл, затем папка восстанавливается. Подтверждены повтор без нового Queue/UI-кадра, повтор неизменённого состояния через App, сохранение самого нового снимка вместо старого неудачного, независимость очереди от изменения входного массива и прежнее завершение/flush Writer.
