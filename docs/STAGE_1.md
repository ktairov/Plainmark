# Этап 1: прототип MyGo

Проверено 3 ноября 2026 года на macOS arm64, Go 1.27.3, MyGo v0.7.4.

## Решение по математике

Выбран `github.com/go-tex/math` v0.50.0. Его baseline-aware SVG API напрямую даёт ширину, высоту и глубину для MyGo `InlineObject`; контуры успешно читаются `ui.ParseSVG` без внешних шрифтов. Геометрия кешируется ограниченным LRU (256 записей), цвет применяется при отрисовке, поэтому светлая/тёмная тема не требуют повторного набора формулы.

Сравнение воспроизводится `go run ./tools/mathprobe` из `next/`. В корпус входят inline-дробь, гауссов интеграл, матрица, cases, aligned, валюта внутри формулы и неизвестная команда.

| Кандидат | Результат корпуса | Интеграция |
| --- | --- | --- |
| go-tex/math v0.50.0 | 6 корректных выражений набраны в SVG и прочитаны MyGo; неизвестная команда отклонена | SVG-контуры и точная baseline-метрика; выбран |
| Luo-Studio/go-tex 60635a3613c5 | 6 корректных выражений преобразованы в PNG; неизвестная команда отклонена | Возможный запасной вариант; не выбран |

Это проверка корпуса, а не доказательство полной совместимости с KaTeX. Растровый вывод второго кандидата не сравнивался пиксельно. Для первого визуально проверены светлый/тёмный снимки просмотра: дроби, индексы, интеграл, матрица, cases и aligned отрисованы. Незнакомые команды остаются текстом.

При проверке найдено отличие парсера MyGo: numeric-dollar эвристика отклоняла часть формул с числами/валютой. Адаптер preview преобразует распознанные `$…$` в `\(…\)`, сохраняет валюту и не трогает code spans/fences. Сценарии закреплены тестами.

## Подтверждённое поведение

- Headless UI: ввод кириллицы, выделение, clipboard, undo/redo, поиск в редакторе, переключение трёх режимов, сохранение с правами исходного файла.
- Файловый тест: внешняя правка не перезаписывается, черновик остаётся в памяти.
- Реальное окно MyGo: smoke запускает новый процесс, редактирует временную заметку, проверяет undo/redo и сохранение, видит обновлённый заголовок preview, вызывает системный Copy и снимает окно.
- Отрисовка формул в preview проверена снимками; SVG не требует WebView.
- Headless UI: таблица, внешняя ссылка и прокрутка по якорю; редактирование и просмотр документа из 2000 параграфов.

## Что остаётся

Прототип пока работает с одним файлом. Дерево, вкладки, watcher, полный диалог конфликтов, шифрование, настройки и импорт состояния реализуются следующими этапами. Навигация между заметками и расширенные сценарии таблиц остаются открыты в плане и чеклисте.
