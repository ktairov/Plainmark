# Этап 5: собственная сессия и локальная сборка

Дата: 4 ноября 2026 года. Собрана версия 0.2.0 для macOS Apple Silicon: `next/build/release/darwin-arm64/Plainmark Go.app`, около 15 МБ. Сборка имеет локальную ad-hoc подпись. Developer ID и нотариализация не выполнялись.

Состояние хранится в `~/Library/Application Support/Plainmark-Go/state.json`, схема version 1. Сохраняются собственные настройки, папки, вкладки, активный документ, режимы, закрепления, позиции и окно. Текст документов, черновики, пароли и раскрытые блоки в схему не входят. Импорт состояния Tauri отсутствует: приложение открывает папку напрямую.

Запись выполняется вне UI-потока, атомарно, с завершением очереди при штатном выходе. Закрытие окна завершает приложение; несохранённые документы защищены диалогом. Отсутствующие документы пропускаются при восстановлении. Явно закрытая пустая сессия остаётся пустой после перезапуска. При первом запуске предлагается выбрать папку.

Исправлена перерисовка после команд нативного меню: изменения состояния и диалоги выхода выполняются через обновление окна MyGo.

Проверки: `go test ./...`; проверки desktop/settings с race detector; сценарий `scripts/lifecycle.py` настоящего приложения, в том числе с race detector. Проверены три запуска с общей отдельной конфигурацией вне репозитория, восстановление вкладок/режима/закрепления/sidebar, штатный выход, отмена выхода с черновиком, discard и пустая сессия. Проверены подпись `codesign --verify --deep --strict` и запуск release-бандла с временной папкой и отдельной конфигурацией вне исходников.

Это локальная сборка для приёмки. Полный ручной чеклист, работа на копии реального архива и запуск на другом Mac ещё требуют проверки; полный перенос не объявляется завершённым.
