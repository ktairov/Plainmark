# Этап 3: workspace и вкладки в интерфейсе

Реализованы дерево с фильтром по пути/заголовкам, закрепления, последние папки, вкладки с отдельными буферами и историей undo, три режима, файловые формы, системное меню и горячие клавиши. Состояние вкладок отделено от отрисовки (`internal/session`); editor/preview/scroll принадлежат конкретному документу.

Переименование и перемещение папки обновляют пути вкладок, закреплений и раскрытых папок. Перетаскивание перемещает файлы и папки; вкладки можно переставлять. Корзина использует MyGo Shell без постоянного удаления как запасного варианта.

Для закрытия вкладок/окна/приложения и смены workspace введены сохранить/отбросить/отмена. Проверка учитывает все затронутые dirty-вкладки. При ошибке сохранения действие не выполняется. Внешние изменения обновляют чистые документы, а dirty-документы сохраняют черновик и показывают конфликт: загрузить с диска, сохранить копию, явно перезаписать. Удалённый извне dirty-документ остаётся открытым.

Watcher подключён к UI. Во время файловой операции обновление откладывается до её завершения. При смене корня старый watcher закрывается; устаревшая загрузка не может изменить новую сессию. Файловая работа выполняется вне UI-потока.

## Проверки

- Headless UI: отдельные черновики и undo после переключения вкладок; Cancel/Save all/Discard при закрытии; сохранение копии при конфликте; rename с dirty-документом; защита смены папки; создание и корзина.
- Реальные pointer gestures headless UI: перетаскивание файла в папку и перестановка вкладок.
- Проверка устаревшего результата после смены workspace и обновления чистых/dirty/удалённых документов.
- Smoke настоящего окна: Unicode, undo/redo, сохранение, preview, системный Copy; запись извне перезагружает чистый документ, сохраняет dirty-черновик и разрешается кнопкой Overwrite.
- `go test ./...`, `go vet ./...`; race-проверки session/desktop/workspace/cryptoblock.

Расширения Markdown, шифрование в UI, локализация и настройки относятся к этапу 4; сохранение собственной сессии между запусками — к этапу 5. По уточнению пользователя импорт состояния Tauri исключён.
