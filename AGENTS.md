# Предпочтения пользователя

- Не собирать и не обновлять сборки Linux и Windows без явного запроса пользователя. Это относится ко всем архитектурам и пакетам, включая Arch-комплекты. Исправления кода сами по себе не являются запросом на обновление этих сборок.

- Для упаковки приложения из `src/` использовать цели Make или `go run ./tools/buildapp`, которые увеличивают номер сборки перед запуском MyGo.
